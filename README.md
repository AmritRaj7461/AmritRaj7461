## 🚀 Co-Engineered Premium Projects

Here are the flagship full-stack and 3D web applications I have built and optimized:

### 👟 VeloStride 3D | Premium 3D E-Commerce Platform
> A high-end, futuristic 3D e-commerce experience showcasing interactive sneaker customization and immersive scrolling physics.
*   **Tech Stack:** `Next.js` • `React Three Fiber` • `Three.js` • `GSAP` • `Framer Motion` • `Tailwind CSS`
*   **Core Systems:** Custom scroll-triggered buildup animations, layered 3D shoe assembly tracking, floating glassmorphic interface, and responsive layout.

### 📝 XampXpress | Advanced Online Exam Platform
> A robust, secure, and highly scalable mock examination platform built for seamless high-concurrency test-taking and real-time grading.
*   **Tech Stack:** `React.js` • `Node.js` • `Express.js` • `MongoDB` • `Tailwind CSS`
*   **Core Systems:** Automated instant scoring engine, robust anti-cheating secure environments, and rich performance analytics dashboard.

### 💉 VacciCare | Intelligent Vaccine Management System
> A complete enterprise-level vaccine tracking, allocation, and booking portal featuring a responsive glassmorphic user interface.
*   **Tech Stack:** `Laravel` • `PHP` • `MySQL` • `Bootstrap` • `Alpine.js`
*   **Core Systems:** Patient tracking dashboard, administrative command center, vaccine batch stock alerts, and high-security session authorization.

### 🤖 NEXUS AI | Hybrid Desktop AI Assistant
> A voice-activated command agent and productivity assistant engineered for sub-second system automation response times.
*   **Tech Stack:** `Python` • `Vosk (Offline Speech Engine)` • `Google Speech API` • `pyttsx3`
*   **Core Systems:** Silent hybrid audio capture, local wake-word trigger constraints, custom system scripts, and dynamic TTS audio outputs.
